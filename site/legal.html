Privacy

  • This site has no accounts, no forms, no cookies and no analytics or advertising scripts.
  • The site is hosted on Vercel, which keeps standard server logs (such as IP address and browser type) to run and secure the service.
  • Audio files are served from GitHub release pages, and artwork for earlier releases is loaded from YouTube (Google). Those providers receive normal request data when your browser loads those files.
